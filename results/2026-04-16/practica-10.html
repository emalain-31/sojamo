Número de secuencias

Para analizar el archivo comprimido sin tener que descomprimirlo, utilizamos zgrep. -c significa que quieres contar las líneas, que vendrán a ser las lecturas. Contará las líneas que empiezan por >, que es el carácter por el que empiezan las secuencias en formato FASTA. De esta manera:

zgrep -c "^>" ../../data/At4.10.fa.gz
13812

Las secuencias que hay en el archivo son 13.812.

Longitudes mínima, media y máxima

Suma los carácteres por secuencia.

zcat ../../data/At4.10.fa.gz | awk ' #descomprime el archivo y awk es el lenguaje para procesar línea a línea
BEGIN {min=1e12; max=0; total=0; count=0; len=0}
/^>/ {
    if (len>0) {
        if (len<min) min=len;
        if (len>max) max=len;
        total+=len; #suma de todos los caracteres, de todos los caracteres de las secuencias
        count++; #numero total de secuencias que ha contado
    }
    len=0;
    next
}
{
    len+=length($0)
} #todo esto se aplica a cada una de las líneas del archivo fasta. cuando termina de leer todas las secuencias...
END {
    if (len>0) {
        if (len<min) min=len;
        if (len>max) max=len; #actualiza los valores de minimos y maximos
        total+=len;
        count++;
    }
    print "Min:", min;
    print "Media:", total/count; #divide la suma de todas los caracteres por el numero total de secuencias contadas
    print "Max:", max;
}'
#con esto hacemos que cuente cuantos caracteres hay en cada línea, en cada secuencia que empieza por >, y las guarda. Al final, con print le decimos que nos muestre de todaas las secuencias que ha contado la que es más corta (longitud mínima), la más larga (longitud máxima) y la media

Cobertura esperada

La cobertura es cuantas veces has leído cada una de las bases del genoma. Se calcula como el cociente de dividir las bases totales entre el tamaño del genoma (19 Mb).

TOTAL_BASES=$(zcat ../../data/At4.10.fa.gz | grep -v "^>" | tr -d '\n' | wc -c)
echo "$TOTAL_BASES / 19000000" | bc -l
13.18944652631578947368

Como es de aproximadamente 13, decimos que cada base se ha leído aproximadamente unas 13 veces. Es suficiente, pero normalmente para que sea de buena calidad se necesita que sea una cobertura de 30 o más. La cobertura es muy dispersa: pueden haber bases que sí hayan sido leídas 13 veces, pero es muy probable que otras solo hayan sido leídas 2 o 3 veces o que incluso algunas bases no se hayan llegado a leer. Es por esto que se considera que el mínimo para ser fiable es una cobertura de alrededor de 30.

¿Genoma haploide o diploide?

En los resultados de la carpeta asm1, encontramos varios archivos que se llaman hap1 y otros hap2, por lo que deducimos que se trata de un genoma con dos haplotipos, es decir, diploide.

Nivel de eliminación de duplicaciones

Ejercicio 3

¿Dónde están las secuencias que componen el ensamblaje?

En los archivos .p_ctg.gfa se encuentran las secuencias, pero como es un grafo contiene el mapa del genoma, las conexiones. Las secuencias están en las líneas S. Podemos convertir el archivo a FASTA y así tener solo las secuencias:

awk '(/^S/){print ">" $2 "\n" $3}' asm1/At4.bp.p_ctg.gfa > asm1/At4.fa

En los archivos .gfa, ¿qué son las líneas que empiezan por ‘A’?

Dan información sobre cómo se asignan las lecturas o contigs a un haplotipo. Deciden qué contig va en cada haplotipo, mejora el phasing y resuelve ambigüedades en regiones complejas. Son información adicional del algoritmo, no son imprescindibles para el ensamblaje final.

¿Qué información tiene los archivos .bed?

Contienen lecturas de baja calidad (lowQ.bed) en formato BED.
